# Veřejná anonymizovaná dokumentace

Zveřejněna je nová čistá historie obsahující hry a zobecněné funkční zadání. Staré commity se zdravotními podklady nejsou součástí veřejného repozitáře.

Z veřejné kopie jsou vyloučeny:

- originální fotografie zdravotního nálezu;
- jméno a příjmení dítěte, rok narození a přesné datum vyšetření;
- přesný osobní věk, podrobná individuální měření a doslovný rodinný přepis;
- metadata původních dokumentů, lokální uživatelské cesty a interní adresy hostingu;
- staré Git objekty, autorství s interními identifikátory a odkazy na původní zdravotní přílohu.

Word dokument byl vytvořen znovu z veřejného generátoru. Obsahuje pouze obecný funkční profil, herní zadání, návrh domácích činností a odborné zdroje. Původní zpráva v něm není skrytá, překrytá ani vložená jako obrázek. Zdrojový kód generátoru také neobsahuje odstraněné údaje.

Označení anonymizovaná specifikace zde popisuje odstranění identifikátorů a zobecnění osobních zdravotních detailů. Dokument není individuální zdravotnickou zprávou. Identita majitele veřejného GitHub účtu je nadále součástí platformy, nikoliv dokumentace.

Kontrolu struktury provádí `python scripts/check-public.py`. Nové dokumenty a skutečné herní exporty je nutné před případným zařazením samostatně prověřit.
